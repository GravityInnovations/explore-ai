# Early K–2 showcase instructions

This is an independent ExploreAI showcase product for learners in Kindergarten through Grade 2, approximately ages 5–7. Adult and teacher viewers are secondary.

- Keep all work inside this folder; never use `examples/playground/` as a source or destination.
- Use the local `.agents/skills/explore-ai` installation and canonical `explore-ai` names only.
- This scaffold is not design acceptance. Do not invent visual direction, lesson topics, catalog entries or runtime capabilities here.
- Complete the ExploreAI designer workflow before building the shared Home/Catalog shell or authoring lessons.
- Preserve the permanent Home `/`, separate Catalog `/catalog`, level → subject → lesson hierarchy and additive generation contract once implementation begins.
